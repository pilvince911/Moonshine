Nouveautés de la 1.0.1

Le raccourci et le démarrage de session utilisent maintenant le lanceur graphique Moonshine.exe pour ouvrir l’icône sans terminal. La mise à jour reprend les anciennes entrées de démarrage reconnues de la 1.0.

La fenêtre propose directement l’installation ou la mise à jour. L’ancienne option de reprise du service 0.9 a été retirée. Voir les changements et les résultats de validation.

Ce que Moonshine regroupe

Bibliothèque intégrée

Analyse les jeux installés reconnus, présente les changements avant de les appliquer et conserve tes réglages de diffusion.

Service Windows

Le lanceur ouvre l’icône sans console à la connexion. Son menu ouvre la bibliothèque, démarre ou arrête le service et donne accès à l’entretien.

Entretien

Répare l’installation, sauvegarde le profil ou exporte un diagnostic. La désinstallation archive le programme et conserve la bibliothèque.

Installer Moonshine

PC hôte Windows 64 bits, client Moonlight et jeux installés avec leurs lanceurs. Usage réel validé sur Windows 11.

  1. Extrais tout le ZIP dans un dossier local.
  2. Ouvre Moonshine.exe et choisis Installer Moonshine. Accepte la confirmation Windows.
  3. Prépare les pilotes signés si le gestionnaire le demande. Redémarre Windows si indiqué.
  4. Démarre le service, ouvre la bibliothèque depuis l’icône, puis appaire ton client Moonlight.

Garde le compte Windows qui utilise les jeux connecté pendant la diffusion.

Mettre à jour Moonshine

  1. Termine ton stream, arrête le service et ferme sa fenêtre. Quitte l’ancienne icône si elle est affichée.
  2. Extrais le ZIP 1.0.1 dans un nouveau dossier.
  3. Ouvre Moonshine.exe et choisis Mettre à jour Moonshine.

Tu retrouves ton catalogue, ton appairage et tes réglages. Les pilotes opérationnels sont réutilisés.

Questions pratiques

Où retrouver l’icône Moonshine?

Regarde sous la flèche des icônes masquées près de l’horloge. Le raccourci Moonshine du menu Démarrer permet de la rouvrir. Fermer la fenêtre de gestion revient à l’icône; quitter l’icône laisse le service dans son état actuel.

Pourquoi un jeu n’apparaît-il pas dans la bibliothèque?

Moonshine analyse les installations reconnues de Xbox PC, Steam et EA. Vérifie que le jeu est installé et que son compte Windows est connecté, puis relance l’analyse. Vérifie l’aperçu avant de synchroniser. Le catalogue complet de l’abonnement Game Pass n’est pas importé.

Quel port utiliser pour Moonlight?

Le port de connexion Moonlight est 48989. Le port 48990 sert à l’interface Web de gestion. Vérifie que le service est démarré depuis l’icône avant d’appairer le client.

Comment régler le DLSS et la Frame Generation?

Active le DLSS et la Frame Generation NVIDIA dans chaque jeu. Les réglages de diffusion d’une entrée restent accessibles dans Moonshine; les réglages graphiques internes du jeu se font dans le jeu.

Comment réparer une installation?

Arrête le service et ouvre Entretien → Réparer depuis le gestionnaire. Moonshine utilise le kit vérifié installé sur le PC et conserve les fichiers remplacés. L’action Exporter un diagnostic prépare les journaux utiles à l’analyse.

Connexion et documentation

La bibliothèque s’ouvre à https://localhost:48990/v2/library sur le PC hôte. Le port Moonlight est 48989. Les jeux utilisent leurs lanceurs installés.

Le ZIP inclut les sources, les licences et les pilotes signés d’origine. Le programme Moonshine est non signé. Le lancement sans console a été validé sur Windows 11; la qualification logicielle couvre aussi le service et le synchroniseur. Consulter les preuves de la 1.0.1.
