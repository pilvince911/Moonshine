Du ZIP à l’icône

Prêt pour ta première partie?

Un PC hôte Windows 64 bits, un client Moonlight et des jeux installés avec leurs lanceurs. L’usage réel a été validé sur Windows 11.

  1. Extrais le ZIP au complet

    Place son contenu dans un dossier local ordinaire.

  2. Ouvre Moonshine.exe

    Choisis Installer Moonshine depuis ton compte habituel et accepte la confirmation Windows.

  3. Suis la préparation des pilotes

    Le gestionnaire indique si les pilotes signés doivent être préparés et si un redémarrage est nécessaire.

  4. Appaire Moonlight et synchronise

    Démarre le service et ouvre la bibliothèque depuis l’icône. Crée tes identifiants, appaire ton client Moonlight, puis analyse et synchronise les jeux.

Tu as déjà Moonshine?

Mets à jour et retrouve tes jeux.

  1. Termine le stream, arrête le service et ferme sa fenêtre. Quitte l’ancienne icône si elle est affichée.
  2. Extrais le ZIP 1.0.1 dans un nouveau dossier.
  3. Ouvre Moonshine.exe et choisis Mettre à jour Moonshine.

Catalogue, appairage et réglages sont conservés. Les pilotes opérationnels sont réutilisés.

Connexion, icône et entretien : les repères pour prendre Moonshine en main.

Où retrouver l’icône Moonshine?

Regarde sous la flèche des icônes masquées près de l’horloge. Le raccourci Moonshine du menu Démarrer permet de la rouvrir. Fermer la fenêtre de gestion revient à l’icône; quitter l’icône laisse le service dans son état actuel.

Pourquoi un jeu n’apparaît-il pas?

Moonshine analyse les installations reconnues de Xbox PC, Steam et EA. Vérifie que le jeu est installé et que son compte Windows est connecté, puis relance l’analyse. Vérifie l’aperçu avant de synchroniser. Le catalogue complet de l’abonnement Game Pass n’est pas importé.

Quel port utiliser pour Moonlight?

Le port de connexion Moonlight est 48989. Le port 48990 sert à l’interface Web de gestion. Vérifie que le service est démarré depuis l’icône avant d’appairer le client. La bibliothèque locale s’ouvre à https://localhost:48990/v2/library.

Où activer le DLSS et la Frame Generation?

Active le DLSS et la Frame Generation NVIDIA dans chaque jeu. Les réglages de diffusion d’une entrée restent accessibles dans Moonshine; les réglages graphiques internes du jeu se font dans le jeu.

Comment réparer une installation?

Arrête le service et ouvre Entretien → Réparer depuis le gestionnaire. Moonshine utilise le kit vérifié installé sur le PC et conserve les fichiers remplacés. L’action Exporter un diagnostic prépare les journaux utiles à l’analyse.
